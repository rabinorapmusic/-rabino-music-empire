# 🧠 CEREBRO - RABINO RAP

**Generador de Dúos + Voz + Acordes con IA**

Cerebro es una app que crea canciones tipo dúo random con artistas famosos. 
Te da la letra, te la canta con voz, y te da los acordes para producirla.

Hecho por Rabino Rap 💿

## 🔥 ¿QUÉ HACE CEREBRO?

1.  **Genera Dúos Random**: Romeo x Karol G, Bad Bunny x Rosalia, etc
2.  **Escribe la letra**: Con tu tema. Ej: "Dembow en Los Alcarrizos"
3.  **Habla**: Te canta la letra con voz usando IA
4.  **Da Acordes**: Te dice tono, acordes y BPM para producir

## 🚀 CÓMO USARLO

1.  Escribe un tema en la caja: `Amor`, `Dembow`, `Desamor`
2.  Dale al botón: `DESPERTAR A CEREBRO 🔥`
3.  Lee la letra, dale play al audio y produce con los acordes

## 🛠️ TECNOLOGÍA

- **Gradio**: Para la interfaz web
- **gTTS**: Para convertir texto a voz en español
- **Transformers**: Para generar letras más duras
- **Librosa**: Para análisis musical y BPM
